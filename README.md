# Texture Generator / シームレス加工

## 導入

Unity 6.0以降向けの独立したEditor用UPMパッケージです。外部ライブラリへの依存はありません。
Package Managerの「Install package from disk」からこのフォルダーのpackage.jsonを選択できます。
Git URLから導入する場合は、Package Managerに次のURLを指定します。

https://github.com/takohachi88/TextureTools.git

パッケージはリポジトリ直下にあるため、?path= の指定やOpenUPMへの登録は不要です。
このフォルダーだけで配布できます。EditorとTestsのasmdef・スクリプトには専用の名前空間を使用しています。
別パッケージから依存させる場合、そのpackage.jsonにはパッケージ名とバージョンを宣言します。Git URLは依存元パッケージのpackage.jsonに書けないため、利用プロジェクトのPackage Managerで本パッケージも追加してください。
## 生成機能

Tools > Texture Generator > 生成 から生成Windowを開けます。Inspectorと同じ設定・プレビュー・PNG/EXR出力を使い、「Presetとして保存…」から通常の保存ダイアログでプリセットを書き出せます。WindowにSOの読み込み機能はありません。画像出力ボタンは最下部に配置しています。

`Assets > Create > Texture Generator > Preset` で設定SOを作成し、Inspectorで編集します。
SO一つが一つのプリセットです。通常の保存ダイアログでAssets配下の任意の場所へ保存でき、変更は通常のアセット保存で保存します。別のパターンを作る場合はSOを複製してください。

- 2D / 3D、解像度、各種ノイズ、セル内UV・中心UV、RGBA別シード、コントラスト、トーンカーブを保存します。
- 生成機能の出力はPNGまたはEXRです。独自の生成アセットとImporterは使用しません。
- 2Dは通常のPNGとして取り込みます。3DはZスライスを行・列に並べたPNG/EXRを出力し、Unity標準TextureImporterのTexture Shapeを3Dに設定します。
- Columns/Rows、リニア色空間、Wrap/Filterを自動設定します。出力後は通常のTextureImporterで設定を編集できます。
- 出力画像は生成設定と連動しない書き出し結果です。設定を変えた場合は再出力してください。

### 出力形式

PNGは0～1の8bit画像、EXRは32bit浮動小数点RGBA（ZIP圧縮）として書き出します。圧縮形式・圧縮品質・プラットフォーム別設定は、出力画像のUnity標準TextureImporterで行ってください。再出力時もこれらの設定は変更しません。
### ビルドへの含有

設定SO、生成コード、InspectorはEditor専用の機能です。PNGはSOを参照しません。通常の未参照プリセットはビルド対象にならず、ResourcesやAddressables等への明示的な登録・参照は通常のUnityアセットと同じ扱いです。

### プレビュー

最初は「プレビューを生成」を押すまで生成しません。一度生成した後は、設定変更から約0.2秒後に自動更新します。Inspectorを閉じて開き直した場合も、最初の生成はボタン操作が必要です。
3Dは全体を一度生成して保持し、Zスライダーの操作では断面を取り出すだけです。コントラスト・カーブ変更はノイズ再生成を伴いません。
RGB/R/G/B/A/RGBA表示、3×3タイル、調整前後のヒストグラムを利用できます。AはUnityのアルファ専用描画を使用します。プレビューは圧縮前RGBAデータで、3Dの分布は選択中の断面です。
ノイズはPerlin / Value / Fractal / Billow / Ridged / White / Voronoi / Block。Hexagon / Triangleは3DではZ方向に押し出した形状です。
CenterU/V/WをRGBに割り当てると、セル中心で画像をサンプリングするモザイク用途に使えます。VoronoiのUVWを組み合わせる場合はRGBのシードを揃えてください。UVは圧縮誤差に敏感なので非圧縮形式が適しています。

### 3D PNGの配置

Columns×Rows=奥行きとなる配置を選び、画像の長辺が短くなるよう並べます。64×64×64は8列×8行の512×512 PNGです。余分な空スライスは作りません。
分割しにくい奥行きでは画像の長辺が伸びます。Editorの最大2D寸法（上限16384px）を超える場合は出力を止め、解像度・奥行きの調整を案内します。
出力画像の寸法に合わせてMax Sizeも設定し、インポート時の意図しない縮小を避けます。

## シームレス加工

`Tools > Texture Generator > シームレス加工`、またはテクスチャの右クリック `Texture Generator > シームレス加工` から開きます。
元画像を半分だけ循環移動し、中央の縦帯・横帯を重ねて継ぎ目を覆います。フェード加工は常に有効です。左右方向と上下方向は個別に選択できます。
縦帯・横帯ごとに「100%領域の全幅」と「片側のフェード幅」を指定します。全幅は `100%領域 + フェード幅×2` で最大1 UVです。
RGBAコントラストとカーブを利用でき、最初のプレビュー生成後は自動更新します。Read/Writeの有効化は不要です。PNG保存時は元画像の解像度・sRGB設定を維持し、元画像と同じ保存先は拒否します。
奇数サイズは半分を切り捨てた移動位置に合わせて加工します。

## Blockパターン

パターンをBlockにすると、大小のセル乱数を補間せずに重ねたブロックノイズを生成できます。2D・3Dに対応します。
横・縦・奥行きのセル数で基準ブロックの大きさを調整します。オクターブ1では各セル内が一定値になり、オクターブを増やすと2倍ずつ細かいブロックを重ねます。「高周波の強さ」で細かいブロックの寄与を調整します。
RGBA別シード、コントラスト・カーブ、XYZの周期的なシームレス生成を利用できます。値はValueを各チャンネルに割り当てて出力します。境界のぼけを防ぐため、PNGのFilter ModeはPointになります。

## Rectangle Layersパターン

ランダムな位置と各辺の長さを持つ矩形を描画順に合成します。3Dでは直方体です。
各図形は加算・乗算・通常合成を等確率で選びます。加算は乱数×強さを加え、乗算はLerp(1,乱数,強さ)を掛け、通常合成は現在値から乱数へ強さの割合で補間します。単独の合成モードの選択はありません。
合成途中は浮動小数点で1を超える値も保持し、最後に出力範囲へ変換します。「濃度分布を均等化」は既定で有効で、4096点の固定座標から得た累積分布によりValueを0～1へ再配置します。基準座標は解像度に依存せず、2Dプレビューと出力、3Dの全スライスで同じ補正になります。
各領域の一定値は保持するため、大きな単色領域や未描画の背景によるピークは残り得ます。完全な一様分布を保証する機能ではありません。トーン・コントラスト調整は均等化後に適用します。均等化無効時は最終値を0～1で切り詰めます。
描画回数256、サイズ0.03～0.25 UV、背景0.5、強さ0.5から調整してください。セル数・オクターブは使いません。シームレス時は矩形のはみ出した部分を反対側にも描きます。
Valueが合成結果です。CellId・セル中心UV・セル内UVは最後に重なった図形の情報で、均等化の対象外です。未描画の領域はCellIdとセル内UVが0、中心UVが0.5です。RGBA別シードとPointでのPNG出力に対応します。

設定項目はパターンと次元に合わせて表示します。Rectangle Layersではセル数、六角形・三角形の3Dでは奥行きセル数、オクターブ1では高周波の強さを表示しません。RGBA別シードが有効な場合は共通シードを表示しません。2Dのチャンネル選択にはW/CenterWを表示しません。

## Multiple Gradients / Curves / HDR

生成モードでNoise、Multiple Gradients、Curvesを切り替えます。Multiple GradientsとCurvesは2D画像を生成します。ノイズ専用のセル数・シード・チャンネル割り当ては表示しません。

Multiple Gradientsは配列順に上から下へグラデーションを並べます。「幅 / 1段の高さ」のYが各帯の高さです。出力全体の高さは「1段の高さ×Gradient数」。HDR対応のGradientから浮動小数点で生成し、左端・右端には0・1の評価値を含めます。

CurvesはRGBAそれぞれのカーブから生成します。左から右へ0～1を評価します。曲線の値は0～1に制限せず、負の値や1を超える値も生成できます。

WindowとPresetの最下部に画像形式の選択と出力ボタンを横一列に表示します。EXRでは新しいモードの生成・書き出しをColor/TextureFormat.RGBAFloatで行い、HDR値を保持します。Multiple GradientsとCurvesにはトーン調整を適用せず、設定した値を直接出力します。トーン調整エリアはNoiseモードでのみ表示します。Noiseの基礎データは従来どおり8bitですが、EXRのトーン処理ではHDR値を出力できます。3DノイズもEXRのスライス画像として出力可能です。画像はUnity標準Importerで取り込み、独自Importerは使用しません。シームレス加工Windowは引き続きPNG出力です。

プレビューも浮動小数点で保持し、ヒストグラムには調整前後の実際の値域を表示します。EXRでは「表示露出 (EV)」で明るさを調整できます。露出は画面表示だけに反映され、ヒストグラム・画像出力には影響しません。細い帯のプレビューは見やすい高さに引き伸ばしますが、出力サイズは変更しません。
## サブモジュールでの開発

開発用のUnityプロジェクトでは、Packages/com.texturetools.generator に本リポジトリをサブモジュールとして配置できます。
そのフォルダーでソースを編集・コミット・Pushし、親プロジェクト側では参照するコミットの更新をコミットします。
親プロジェクトを初めて取得するときは git clone --recurse-submodules を使用し、既存のチェックアウトでは git submodule update --init --recursive で取得します。
他の開発者の親プロジェクト更新時にはサブモジュールのコミットが切り替わるため、変更を始める前に本リポジトリの作業ブランチへ切り替えてください。
